# Shiddiqi Group — Website

Website profil bisnis responsif berbasis HTML, CSS, dan JavaScript vanilla.

## File
- `index.html` — struktur dan isi website
- `style.css` — tampilan responsif, ilustrasi vektor CSS, dan layout
- `script.js` — navigasi mobile, tahun otomatis, dan draft inquiry via email
- `README.md` — petunjuk

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser, atau jalankan server lokal sederhana.
3. Untuk publikasi, unggah ketiga file website ke hosting statis (mis. cPanel, Netlify, atau GitHub Pages).

## Sebelum publikasi
Periksa dan ganti:
- Email, WhatsApp, alamat kantor, Instagram/LinkedIn resmi.
- Pastikan nama legal dan nomenklatur entitas/unit bisnis.
- Pastikan seluruh klaim aset, lokasi, luas, harga, legalitas, akses, dan ketersediaan sudah diverifikasi.
- Listing tanah ±1.950 m², perimeter ±180 m, dan harga Rp250 juta di halaman merupakan detail draft/contoh yang perlu dikonfirmasi.
- Pembanding harga yang ditautkan merupakan harga penawaran listing, bukan harga transaksi terverifikasi atau valuasi profesional.
- Formulir inquiry saat ini hanya menyiapkan draft email `mailto:`; tidak ada database/backend dan belum mengirim ke alamat perusahaan secara otomatis. Atur `mailto:` dengan alamat resmi atau integrasikan layanan form sebelum live.
- Pastikan hak penggunaan foto, logo, serta seluruh materi promosi.

## Teknologi
Tanpa framework, build step, atau dependensi JavaScript eksternal. Font Google Fonts membutuhkan koneksi internet; fallback font tersedia.
